在WordPress文章编辑页集成AI写作辅助工具，兼容任意OpenAI格式接口的服务商。

== Description ==

AI文章润色助手是一款轻量级 WordPress 插件，让你在写文章时直接调用你在插件页设置的AI服务商配置进行润色、扩写、缩写、续写、生成摘要、SEO 标题建议和多语言翻译。

**核心特性：**

* 兼容任意OpenAI Chat Completions 格式的接口（官方 API、代理中转、自建网关、DeepSeek、Moonshot 等国产模型均可以使用）
* API密钥使用AES-256加密后存储于数据库，避免明文泄露
* 同时支持Gutenberg区块编辑器与经典编辑器 (TinyMCE)
* 内置8种常用写作功能，且可自由启停
* 支持自定义Prompt模板，固定你常用的写作指令
* 每用户每日调用次数限制，防止API额度被滥用
* 完整的使用记录日志（用户、文章、功能、Token 消耗）
* 一键测试AI服务商连接
* 支持WP-CLI命令行操作
* 卸载插件时是否清除数据可自由选择

= 支持的功能 =

1. 智能润色 —— 保留原意，提升表达流畅度
2. 扩写内容 —— 补充细节与例证
3. 精简/缩写 —— 去除冗余，保留核心信息
4. AI 续写 —— 承接原文风格继续创作
5. 生成摘要 —— 一键生成150字以内摘要
6. SEO 标题建议 —— 生成5个候选标题
7. 多语言翻译 —— 翻译为任意目标语言
8. 要点提炼 —— 一键提取全文/选中内容的核心要点列表

== Installation ==

1. 上传插件 zip 包，或将 `ai-f-assistant.php` 文件夹上传至 `/wp-content/plugins/` 目录
2. 在 WordPress 后台"插件"页面启用本插件
3. 进入"设置 → AI 润色助手"，填写你的AI服务商接口地址与API密钥
4. 点击"测试连接"确认配置正确
5. 打开任意文章编辑页，右上角工具栏（或经典编辑器侧边栏）即可看到AI助手面板

== Frequently Asked Questions ==

= 支持哪些AI服务商？ =

任何暴露标准 `/v1/chat/completions` 接口、且遵循OpenAI请求/响应格式的服务商都可以使用，包括官方 OpenAI、Azure OpenAI（需自行拼接兼容路径的中转）、DeepSeek、Moonshot（Kimi）、通义千问兼容模式、以及各类自建/中转网关。

= API密钥安全吗？ =

密钥不会以明文存储。插件使用AES-256-CBC对称加密，密钥派生自你站点`wp-config.php`中的 `AUTH_KEY` 等安全salt，仅当需要实际调用接口时才会在服务器内存中临时解密，不会展示明文密钥。

= 可以限制普通作者的调用次数吗？ =

可以，在设置页"高级选项"中设置"每用户每日调用上限"，0表示不限制。
